#  BPMN 2.0

## Назначение BPMN
BPMN — стандарт графического описания бизнес-процессов, обеспечивающий однозначное понимание между бизнес-аналитиками, разработчиками и менеджерами. Отличается от блок-схем строгой семантикой.

## Таблица элементов нотации

| Элемент | Обозначение | Значение | Пример |
|---------|-------------|----------|--------|
| Start Event | Круг с тонкой линией | Начало процесса | «Получена заявка» |
| End Event | Круг с жирной линией | Завершение ветки | «Заказ выполнен» |
| User Task | Прямоугольник с иконкой человека | Задача, выполняемая человеком | «Проверить документы» |
| XOR Gateway | Ромб с X | Исключающее ИЛИ | выбери один из двух путей |
| Collapsed Sub-Process | Прямоугольник с плюсом [+] | Детализация на другом листе | «Обработать платёж» |

## Типы шлюзов (сравнение)

| Тип | Условие применения | Пример | Ошибка |
|-----|---------------------|--------|--------|
| XOR | Нужен ровно один из путей | Выбор способа доставки | Отсутствие подписи условий |
| AND | Все пути выполняются | Отправка уведомления и SMS | Использование вместо XOR |
| OR | Один или несколько путей | Применить скидку при акции | Избыточная сложность |

## Чек-лист проверки диаграммы BPMN
1. Есть ли у каждого шлюза подписанные условия на всех исходящих потоках?
2. Не пересекает ли Sequence Flow границу пула?
3. Все ли задачи имеют глагольное имя?
4. Один ли Start Event в пуле (если не событийный подпроцесс)?
5. Каждая ли завершающая ветка имеет свой End Event?
6. Используется ли Message Flow только между разными пулами?
7. Нет ли «висящих» стрелок, не соединённых с элементами?
